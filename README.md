# Sìshēng (四声)
A CLI tool for drilling single tones and tone pairs, written from scratch in C.

Sisheng (四声) literally means "Four Tones" in Mandarin Chinese.

It is currently a work in progress. This project is being worked on without AI assistance, for the sake of learning.

## Development
To build and run:
```sh
gcc main.c -o build && ./build
```
